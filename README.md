# Sakhi Hub

Build a modern, simple, mobile-friendly dashboard page called “DLE Work Hub” for DLE Sakhi, a platform for rural women entrepreneurs (DLEs) working with Dharmalife Foundation.

The dashboard should be very easy to understand for a user who may not be highly technical.

Main Goal

When a DLE opens the dashboard, she should immediately understand:

What should I do today?

How much money have I earned?

How am I performing?

What impact am I creating?

What should I learn next?

Do NOT make it look like a complicated business analytics dashboard.

PAGE STRUCTURE

1. Header

Show:

“Good Morning, Lakshmi! 👋”

Below it:

“Here’s what you need to focus on today.”

Add a simple profile icon on the right.

2. Today’s Tasks — MOST IMPORTANT SECTION

Create a prominent card titled:

“🎯 Today’s Tasks”

Show 3 simple tasks:

Visit 3 customers

Complete 2 household surveys

Follow up with 2 customers

Each task should have a checkbox and a button:

“Start”

When the user clicks Start, visually mark the task as active/completed.

Also show:

“3 important tasks for today”

Use simple colors to distinguish priority, but keep the design clean.

3. My Earnings

Create a large card titled:

“💰 My Earnings”

Display:

₹4,850

Goal: ₹6,000

Add a progress bar showing approximately 80%.

Below it write:

“₹1,150 more to reach your goal”

Then show a small breakdown:

Product Sales — ₹3,600
Surveys — ₹900
Bonus — ₹350

Add a small button:

“View Earnings”

4. My Progress

Create a simple section titled:

“📊 My Progress”

Show four statistics in simple cards:

25 — Products Sold

42 — Households Reached

18 — Surveys Completed

₹4,850 — Earned

Use icons and large numbers.

Do not use complicated charts.

5. My Impact

Create a section titled:

“🌱 My Impact”

Show:

42 Households Reached

18 Women Reached

15 Clean-Energy Products Sold

Add a friendly message:

“Your work is helping your community. ❤️”

Make this section visually warm and positive.

6. Recommended Learning

Create a card titled:

“🎓 Learn Something New”

Show:

“How to explain Solar Lamps to customers”

Duration:

“8 minutes”

Add a button:

“Start Training”

Below the card show:

“Complete training to earn +10 Skill Points”

When the button is clicked, show a simple training-start state/modal.

7. My Achievements

Create a section titled:

“🏆 My Achievements”

Show achievement badges:

✅ First Sale

✅ 10 Households Reached

🔒 50 Products Sold

Add text:

“8 more sales to unlock the next badge!”

Keep this simple and motivating.

DESIGN STYLE

Use a clean, modern, friendly design suitable for rural women entrepreneurs.

The design should feel:

Warm

Trustworthy

Simple

Professional

Encouraging

Easy to use on mobile

Use rounded cards, clear icons, large readable text and plenty of spacing.

Avoid:

Overly complicated graphs

Too many numbers

Crowded screens

Technical terminology

Excessive animations

Use a soft natural color palette inspired by sustainability and rural communities, with green as the primary accent.

RESPONSIVE DESIGN

The dashboard must work properly on:

Mobile phones

Tablets

Desktop

On mobile, stack the cards vertically.

On desktop, use a clean grid layout.

NAVIGATION

Create a simple sidebar on desktop and bottom/mobile navigation on mobile.

Navigation items:

🏠 Home
💰 Earnings
📊 My Progress
🎓 Learning
🏆 Achievements

The Home page should be the DLE Work Hub dashboard described above.

IMPORTANT

This is a prototype for a hackathon.

Make the interface look polished and realistic, but use mock data for now.

Make all important buttons interactive.

For example:

Start task → task becomes active/completed

Start Training → opens a training modal/page

View Earnings → opens earnings details

Achievement badges → show progress

Checkbox → updates task completion

Do not build the backend yet.

Focus on creating a beautiful, functional frontend prototype for the DLE Work Hub.for dharmalife social organization
